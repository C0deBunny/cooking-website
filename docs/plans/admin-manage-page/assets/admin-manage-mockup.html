Row anatomy — four columns, deliberately

Chevron · Title · Status badge (centred under its header) · Updated (relative, from the updated_at trigger) · four right-aligned icon actions. Slug, difficulty and time were pulled out of the row and live in the panel — the collapsed row answers "which recipe, is it live, how stale is it" and nothing else.

Draft rows carry their warning

A draft has no public URL, so view on site is disabled on those rows rather than 404-ing. Expand a draft to see the "not visible to visitors" note.

4 · What this mockup is quietly asserting

trap The read cannot be getRecipes()

That one is anon + "use cache", so RLS hides every draft. Manage needs getAllRecipesForAdmin() on the server client, uncached. If you forget, the page looks fine and just never shows drafts.

trap Row click vs. action buttons

An action button inside a clickable row bubbles up and expands it too. The buttons need stopPropagation, or the click target must be the chevron cell alone.

trap Publish still has to bust the public cache

Manage is uncached so it refreshes for free — but /recipes is cached under cacheTag("recipes"). Publish and delete must call updateTag.

deferred No open/close animation in v1

Prototyped and dropped. It works — a grid-template-rows: 0fr → 1fr wrapper inside a zero-padding <td>, since table layout will not tween a <tr> itself — but it forces every panel to stay mounted, and it is pure polish. Cheap to add back later.

Detail row unmounts when closed

Only the open row's panel exists in the DOM. That is a consequence of dropping the animation, not an independent choice — a transition needs something to animate from.

Accordion, one openId

One row open at a time, so the state is number | null rather than a Set. Opening B while A is open runs both transitions at once, which reads as a handoff rather than two separate moves.
