Deliberate omissions — everything the reference layout had that this does not

  • ✕Category, Cuisine— no such columns on recipes. Adding them is a migration, not a form change.
  • ✕Recipe image— no Storage bucket exists (docs/image-storage.md). image_path stays null.
  • ✕Slug field— derived from the title, read-only, never editable. A 23505 collision just says choose a different title.
  • ✕Notes field— deferred. The column stays, the form sends null.
  • ✕Tags— sidebar placeholder only; no schema behind it yet. Still open in the README.
  • ✕Save Draft button— one save, on Review. The publish switch decides draft vs live.
  • ✕Autosave / refresh recovery— out of scope; to be logged in docs/known-issues.md.
  • ✕Ingredient groups— removed outright, not just hidden: group_label dropped from recipe_ingredients, read out of save_recipe(), and hasContiguousGroups deleted from the zod schema. Supersedes decision 7 of recipe-schema-redesign.

Mockup scaffolding — present here, not to be built

  • ◇The swatch strip under Difficulty— marked .mock-only and blue-tinted wherever it appears. It exists so all three badge colours can be judged side by side; the real Details panel shows no badge at all, only the select. The badge renders in the preview, the article and the Review checklist.
  • ◇The toolbar (Dark / Prefilled / Slug collision)— state toggles for inspecting this file. No equivalent in the app.
  • ◇The browser frame and the sidebar rail— context only; the rail already exists.

New shared pieces this slice introduces

  • ＋<DifficultyBadge />— components/shared/, backed by six new tokens in globals.css. Used by the article, the live preview, RecipeCard and the manage table. Not mapped onto --secondary/--primary/--destructive: “hard” must not track your danger colour.
  • ＋Split zod schemas— detailsSchema · ingredientsSchema · stepsSchema, composed into recipeSchema. Drives the stepper's ✓ marks.
  • ＋Numeric fields are inputMode="numeric" text, sanitised on input— not type="number": no spinner means the suffix has the right edge to itself. Prep/Cook/Servings take digits only; ingredient Amount also takes a comma, a dot or a fraction (1/2, 0,5), normalised to a decimal in the payload. Sanitising is what lets the ✓ come straight from zod.
  • ＋Fractions in formatAmount()— 0.5 → ½, 1.5 → 1½, 0.25 → ¼. The column stays numeric; the public page gets this too.

Structural decisions you can't see

  • §Steps 1–3 are not inside a <form>— only the Review panel is. Enter therefore cannot submit from a half-filled step, because there is no form to submit into. The hidden payload field reads React state, so the inputs living outside the form costs nothing.
  • §The preview is gone below 1024px— AdminSidebar is collapsible="none" with a fixed rail, so /admin is already desktop-first. Resize this page to see it.
  • §The slug follows the title, forever— including on edit, where a rename changes a live URL. Edit warns on this line before saving; create doesn't, because nothing is linked yet.
