What the real values turned up

The dark sidebar ramp was never themed

Dark --background is a warm oklch(0.18 0.012 75), but every dark --sidebar-* token is pure neutral grey — stock shadcn defaults sitting untouched inside a warmed theme. The rail reads visibly colder than the page it lives in. Bigger than the white-border bug I flagged earlier.

Dark --sidebar-primary is blue

It is oklch(0.4878 0.2432 264.4045) — byte-identical to --chart-4. A chart colour leaked into the sidebar ramp. Nothing currently reads it, and the proposed accent bar uses --primary instead, so this is latent rather than visible. Worth fixing while the file is open.

The accent bar survives dark mode

Dark --primary is oklch(0.75 0.183 55.934) — the same orange as light. So bg-primary on the active marker stays orange in both themes and needs no dark-mode special case.

Row radius does most of the work

--radius: 1rem makes rounded-md compute to 14px. On a 32px row that is nearly a lozenge, and it is what makes the current rail read as floating blobs. Dropping to ~6px is the single change with the biggest effect, before any colour is touched.

Caveats: the site font is Alan Sans, unavailable offline — this mock uses a system stack, so weights and metrics differ slightly. Panels are scaled to roughly 65% of real size; the real rail runs about three times the height shown, so the empty region is proportionally larger than it looks here.
